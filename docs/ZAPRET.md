# Интеграция zapret

Установка предназначена для Raspberry Pi OS Lite Trixie arm64. Служба
`raspberry-tv-zapret.service` управляет отдельным процессом nfqws и таблицей
`inet raspberry_tv_zapret`. Оболочка общается со службой через локальный Unix
socket, доступный группе `raspberry-tv`; произвольные команды и пути не принимаются.

## Источники и сборка пакета

- [Linux-адаптер Sergeydigl3](https://github.com/Sergeydigl3/zapret-discord-youtube-linux/tree/69db771b527ba11ca71efe28728a7f9491eec352): используется неизменённый `parse_bat_file`.
- [Стратегии Flowseal](https://github.com/Flowseal/zapret-discord-youtube/tree/ef19845a801e4e743f7bdfdbd58f9745c6adbd60).
- [nfqws v72.9](https://github.com/bol-van/zapret/releases/tag/v72.9): Linux arm64.

Версии и SHA-256 архивов закреплены в `deploy/zapret-sources.json`. Подготовка
не требует root: `python3 scripts/prepare-zapret.py`. Предпочтительно выполнять
на Pi: Windows Defender на этом ПК удаляет общий release-архив с детектом
`Trojan:Win32/Suschil!rfn`. Защита не отключалась, исключения не добавлялись.
Это сообщение о детекте, а не доказательство безопасности остальных файлов.
В конечный пакет входят только ARM/Linux nfqws, текстовые стратегии, их данные
и документация; Windows-исполняемые файлы не включаются.

После распаковки пакета в отдельный каталог:
`python3 scripts/check-zapret.py /абсолютный/путь/к/пакету` проверяет настоящим
nfqws `--dry-run` все 22 стратегии в четырёх сочетаниях GameFilter.
Файлы имеют ненулевой mtime: nfqws не принимает списки с датой Unix epoch.

Установка: `sudo bash scripts/install-zapret-pi.sh /путь/raspberry-tv-zapret-assets.tar.gz`.
Инсталлятор проверяет контрольные суммы, ставит системную службу и обновляет
модули оболочки. При первой установке обработка **выключена**. После установки
перезапусти пользовательскую оболочку: `systemctl --user restart raspberry-tv`.

## Управление с телевизора

Настройки → Сетевые правила: выбери профиль, домены, установленную стратегию и
интерфейс (`wlan0` для текущего Wi-Fi). «Применить и включить» запускает пробное
изменение. В течение 60 секунд выбери «Оставить изменения», иначе служба вернёт
прежнее состояние независимо от работы GUI. Подтверждённые настройки сохраняются
после перезагрузки. «Откатить изменение» возвращает состояние перед последним
применением. Перезагрузка во время пробного изменения также приводит к откату.

Подбор перебирает установленные стратегии, проверяет HTTPS введённых доменов и
в конце возвращает прежние правила. Его можно остановить. Результаты позволяют
выбрать стратегию в черновик; она применяется отдельным действием с подтверждением.
Проверяются до 10 доменов, DNS/HTTPS имеют таймауты. Ответ HTTP 403/404 тоже означает
успешный TLS, но не подтверждает воспроизведение видео. У корневых CDN-доменов
может не быть веб-страницы или DNS-записи; для проверки используй обслуживаемый
хост вроде `www.youtube.com` или `i.ytimg.com`. QUIC и потоковое видео требуют
отдельной реальной проверки. Результаты подбора пока хранятся до перезапуска службы.

## Границы обработки и восстановление

Параметры DPI стратегий сохраняются. Их исходные положительные hostlist/ipset
заменяются списком доменов из GUI; исключения сохраняются. Это важно: простое
добавление списка не сужает объединение upstream-списков. Поддомены включаются
автоматически. GameFilter TCP/UDP расширяют порты независимо, сохраняя ограничение
по доменам; протокол без распознаваемого домена не получает широкую обработку.
Голос Discord/STUN и произвольные игры этим режимом не гарантируются.

Firewall backend — nftables, единственный доступный в этом профиле. Пакеты на
private/link-local/multicast адреса, SSH 22 и стандартные порты Sunshine/Moonlight
не отправляются в NFQUEUE. Локальный Moonlight исключён при любых портах.
Публичный Sunshine с нестандартными портами потребует отдельного исключения.
Порты взяты из [документации Sunshine](https://docs.lizardbyte.dev/projects/sunshine/latest/md_docs_2configuration.html).
Таблицы других программ не очищаются. Очередь 221 использует `bypass` при
отсутствии обработчика; при остановке службы удаляется только её таблица.
Маршруты, forwarding и системные DNS-настройки не меняются.

Аварийная остановка по SSH: `sudo systemctl stop raspberry-tv-zapret.service`.
Журнал: `journalctl -u raspberry-tv-zapret.service -n 100 --no-pager`.
Состояние и откат: `/var/lib/raspberry-tv-zapret/state.json`, доступ на запись только root.

## Проверено на Pi 2026-09-05

Установлена и включена служба; выбран YouTube, `general (ALT).bat`, `wlan0`,
оба GameFilter выключены. Автоподбор проверил 22 стратегии по `www.youtube.com`
и `i.ytimg.com`, 7 прошли оба HTTPS-запроса. У YouTube HTTP 200, у корня сервера
миниатюр ожидаемый HTTP 404. Стандартная `general.bat` в этой сети не сработала.

Проверены запуск/остановка, ручной откат, автоматический откат через 60 секунд
с удалением собственной nft-таблицы, принудительное завершение управляющего
процесса во время пробного изменения и восстановление прежнего состояния.
Подтверждённый профиль пережил перезапуск системной службы; доступ к YouTube
перепроверен. SSH и GitHub оставались доступны. nfqws работает как `nobody`.
Для перехода UID при фильтрах systemd на этой ОС требуется
`AmbientCapabilities=CAP_SETUID`; `CAP_SETPCAP` нужен движку для сброса capabilities.

Windows: 45 тестов прошли, 2 Linux-теста пропущены. На Pi: 39 тестов ядра
прошли, 88 проверок реального ARM nfqws `--dry-run` прошли. nft-правила сначала
проверены в отдельном network namespace, затем применены самой службой.
Пользователь подтвердил воспроизведение видео и звука YouTube на телевизоре.
Используемый браузером протокол (TCP/QUIC), аппаратное декодирование,
длительное воспроизведение и игра Moonlight отдельно не измерялись.
