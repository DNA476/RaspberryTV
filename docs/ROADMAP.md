# План развития

Пункты ниже — будущие изменения, **не реализованные в текущей публикации**.
Новые пожелания зафиксированы 2026-09-05; сейчас они добавлены только в документацию.
Состояние уже работающих функций описано в [STATUS.md](STATUS.md).

## Следующие изменения интерфейса

### Меню питания в правом верхнем углу

- [ ] Заменить угловой значок настроек кнопкой питания: удобная плитка
  **Настройки** уже даёт основной вход в настройки и остаётся на главном экране.
- [ ] По кнопке питания открывать меню **Выключить / Перезагрузить / Спящий режим**.
- [ ] Сохранить подтверждение выключения/перезагрузки, отмену и управление геймпадом.
- [ ] Проверить доступность сна на Pi 5 с используемым ядром/прошивкой, способы
  пробуждения и восстановление HDMI, сети и Bluetooth. Если обычный suspend
  недоступен, согласовать поведение режима ожидания и его название; выключение
  экрана само по себе не считать полноценным сном устройства.

Критерий готовности: кнопка доступна с главного экрана и геймпада; выход из меню
возвращает фокус; для сна есть проверенный способ пробуждения без повреждения
состояния приложений. Сейчас угловая кнопка по-прежнему открывает настройки,
а меню питания доступно через F3/удержание PS и не содержит спящего режима.

### Отдельная плитка браузера

- [ ] Добавить **Браузер** как отдельную плитку рядом с существующими приложениями.
- [ ] Предусмотреть ввод адреса, переходы назад/вперёд и навигацию только геймпадом.
- [ ] Сохранить отдельный сценарий YouTube, возврат Home и быстрое меню поверх браузера.
- [ ] Определить стартовую страницу и использование профиля браузера.

Критерий готовности: браузер открывается независимо от YouTube, позволяет ввести
URL и вернуться в оболочку; повторный запуск корректно возвращает его окно.

### Экранная клавиатура поверх сторонних приложений

Проблема: при использовании только геймпада ввод текста в сторонних приложениях
затруднён. Клавиатура лаунчера сейчас обслуживает только его собственные поля.

- [ ] Дать возможность вызвать клавиатуру геймпадом поверх Chromium, Kodi и других
  локальных приложений; выбрать понятную кнопку/сочетание или пункт быстрого меню.
- [ ] Исследовать автоматический показ при фокусе текстового поля. Там, где
  приложение не сообщает о поле, оставить ручной вызов.
- [ ] Использовать привычный вид и навигацию клавиатуры лаунчера: латиница,
  кириллица, цифры, символы, пробел, удаление и Enter.
- [ ] Сохранять целевое поле и отправлять ввод именно в него, пока фокус управления
  находится на клавиатуре; корректно возвращать фокус при закрытии.
- [ ] Проверить ввод URL/поиска YouTube, поиск в Kodi и парольные поля; введённый
  текст и пароли не должны попадать в журналы.
- [ ] Отдельно определить поведение в Moonlight: ввод в удалённый ПК отличается
  от ввода в локальное окно.

Критерий готовности: с одним DualSense можно открыть приложение, ввести текст,
исправить его, подтвердить и закрыть клавиатуру без мыши и физической клавиатуры.
