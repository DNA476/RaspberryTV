# Moonlight и Sunshine

Этот этап добавляет Moonlight Qt в X11-сеанс Raspberry TV на Pi 5 / Trixie arm64.
Официальный пакет `6.1.0-4` установлен на Pi; сопряжение с Sunshine
на Windows и чтение списка приложений подтверждены после установки. Игровая сессия,
аппаратное декодирование, звук и управление ещё требуют ручной проверки.

## Установка на Pi

После основной установки Raspberry TV выполни из каталога проекта:

```bash
sudo bash scripts/install-moonlight-pi.sh
```

Скрипт использует официальный репозиторий Moonlight Qt для **Raspbian**, проверяет
полный отпечаток ключа `402E1E45A2456EDCF32A5E0E2F6AE14E1C660D44`, добавляет его через
`signed-by` и устанавливает `moonlight-qt` с зависимостями. При отсутствии GnuPG
сначала устанавливает `gnupg` и `ca-certificates`. Общего обновления ОС не запускает.
На проверенной Pi нужны два новых пакета: Moonlight Qt и `qt6-svg-plugins`.
Перезагрузка обычно не требуется. Существующий PipeWire остаётся звуковым сервером.

Основной установщик не включает этот пакет: игровой ПК нужен не всем.
После обновления исходников существующей установки также обнови код лаунчера
по [INSTALL.md](INSTALL.md), чтобы плитка запускала `moonlight-qt`.

Основа установки — [официальная инструкция для Raspberry Pi 4 и более новых моделей](https://github.com/moonlight-stream/moonlight-docs/wiki/Installing-Moonlight-Qt-on-Raspberry-Pi-4).
Она рекомендует консоль для максимальной производительности. Здесь выбран X11,
чтобы сохранить меню и возврат в Raspberry TV; производительность этого пути
нужно проверить на реальной трансляции. HDR в начальном профиле выключен.

## Подключение игрового ПК

1. Установи и запусти [Sunshine](https://docs.lizardbyte.dev/projects/sunshine/latest/) на игровом ПК.
   Pi и ПК должны быть доступны друг другу в локальной сети.
2. Открой плитку **Moonlight**. Выбери обнаруженный компьютер; если он не появился,
   добавь его локальный IP через кнопку добавления компьютера.
3. Moonlight покажет PIN. На игровом ПК открой Sunshine → **PIN**, введи этот код
   и подтверди подключение. Пароль Sunshine вводится только в его веб-интерфейсе.
4. Открой компьютер в Moonlight, затем **Desktop**, **Steam Big Picture** или игру,
   настроенную на стороне Sunshine. Повторное сопряжение при каждом запуске не нужно.

Для диагностики из SSH под тем же пользователем Pi:

```bash
QT_QPA_PLATFORM=offscreen moonlight-qt list IP_ИГРОВОГО_ПК
```

Успешный список приложений подтверждает сопряжение и управляющее соединение,
но ещё не проверяет передачу видео по UDP.

## Начальный профиль и управление

При первом запуске плитки отсутствующие параметры получают значения: **1280×720,
60 FPS, 10 Мбит/с, HEVC, SDR**, автоматический выбор декодера, полноэкранное окно
без рамки. Позднейшие изменения качества в настройках Moonlight сохраняются.
Автоматический декодер может перейти на программный: аппаратное ускорение
подтверждай статистикой и журналом сессии, а не выбранным кодеком.
Для плавных 60 FPS выбери на телевизоре/Pi режим 60 Гц. При выводе 50 Гц можно
выбрать в Moonlight 50 FPS; лаунчер не переключает HDMI сам.

Для меню Raspberry TV лаунчер при каждом новом запуске клиента выключает
**background gamepad** и захват системных клавиш. Только дочерний Moonlight получает
`SDL_JOYSTICK_HIDAPI=0`: ввод идёт через evdev, где действует временный перехват
геймпада меню лаунчера. Специальные функции DualSense и вибрация требуют отдельной
проверки; полная передача возможностей контроллера этим этапом не обещается.

- **PS / F1** — главный экран; повторный выбор плитки возвращает приложение.
- **Options / F2** — быстрое меню; возврат должен восстановить окно трансляции.
  Options зарезервирована оболочкой; исходное нажатие может также открыть меню игры.
- Треугольник и квадрат в Moonlight остаются кнопками геймпада; F/Esc не отправляются.
- Тачпад предоставляет указатель, прокрутку и ЛКМ/ПКМ через обычный ввод Pi.
- **Options → Закрыть приложение** завершает локальный клиент. Это не команда
  выключения игрового ПК и не гарантия закрытия игры на нём.

Экранная клавиатура Raspberry TV пока не отправляет текст в удалённую Windows.
Для игрового интерфейса используй Steam Big Picture и его клавиатуру; для настройки
обычных программ может потребоваться клавиатура игрового ПК. Отдельная интеграция
удалённого текстового ввода остаётся в плане.

## Ручная приёмка

1. С DualSense открой плитку, выбери ПК и **Desktop**. Проверь изображение и звук.
2. Запусти Steam Big Picture и игру. Проверь крестовину, оба стика, триггеры,
   X/O/квадрат/треугольник и вибрацию. Повтори по USB и Bluetooth.
3. Проверь тачпад, ЛКМ слева, ПКМ справа и прокрутку.
4. Во время игры открой Options, походи по меню и отмени. Проверь, что дальнейшая
   навигация по меню не управляет игрой, после возврата кнопки и стики не залипли.
5. PS → главный экран → Moonlight: возвращается текущая трансляция. Заверши
   трансляцию в Moonlight и проверь возврат к списку приложений.
6. Закрой клиент из быстрого меню и открой заново. ПК остаётся сопряжённым.
7. Поиграй 10–15 минут с действующим профилем zapret. Проверь задержку, рывки,
   рассинхронизацию звука и обрывы. Включи статистику Moonlight при необходимости.

Журнал клиента находится в `~/.config/raspberry-tv/state/moonlight.log` при стандартном
каталоге настроек. В нём могут быть локальные адреса и запросы сопряжения: перед публикацией
убирай их. Файл `~/.config/Moonlight Game Streaming Project/Moonlight.conf` содержит
ключи клиента и сведения о сопряжении; его целиком в отчёты не включай.
